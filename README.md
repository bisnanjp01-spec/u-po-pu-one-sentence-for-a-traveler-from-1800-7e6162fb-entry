One sentence of at most 200 characters that explains the modern internet to a time traveler who has just stepped out of the year 1800, built only from words and pictures a person from that year already knows: a spider's web, a thread, a letter, a town. The program writes the sentence to `/output/entry.txt`, and refuses to write anything that is not exactly one sentence inside the 1–200 character gate.

## Run it

```sh
node main.ts
```

## The sentence

Think of a spider's web spun over the whole earth, where a tug on one thread brings the letter you ask for from any town to your hand before the hour is out.
